**🔬 MC knockout-model audit (2026-06-12, collaborator challenge → CONFIRMED; awaiting user decision on republishing)**:
- **The issue is real**: after a 90-min Poisson draw in knockouts, penalties/extra time are resolved as a **Bernoulli at the Elo expectancy eA** (`ko_win_prob` in `scripts/world-cup/mc-sim.py`: `win + ea*draw`) → the favorite's strength is double-counted (once in the goal model, again in the shootout; real shootouts are near coin flips). On top of that, the λ split (λA = 2.6·eA) is itself more decisive than the Elo expected score, so a 0.70-expectancy favorite advances with probability 0.777 (**+7.7pp per round**), compounding over up to five knockout rounds.
- **Magnitude** (same seed=20260611, 100k control reruns): Spain champion **37.83% (published) → 30.53% (pens=50/50) → 27.29% (pure Elo Bernoulli)**; Argentina 24.41 → 21.27 → 19.44. Fully explains the collaborator's "everything I compute is <35%".
- **Blast radius**: champion / reach-qf / reach-sf pools + bracket (`bracket-prediction.json`) + the site's champion-page numbers; **the 12 group winners and 72 single-match forecasts are unaffected** (the former depends only on the group stage; the latter use the Davidson three-way model).
- **"Squared average" clarified**: the √ the collaborator's Claude saw is the Davidson draw term ν·√(pA·pB) in the single-match model (geometric mean, standard, fine); the MC shootout rule uses bare eA. Two different formulas — the problem is only the latter.
- **MC code now committed**: canonical `scripts/world-cup/mc-sim.py` (repo-relative paths, **bit-for-bit reproduces the published `mc-results.json`** on the same seed, ~5s per run); the sprint's one-off generator scripts (reach-qf/sf builders, champion generator, deterministic validator, 9 files) archived verbatim under `runtime-artifacts/world-cup/code-archive/` (contain absolute paths; provenance archive, not reusable tooling).
