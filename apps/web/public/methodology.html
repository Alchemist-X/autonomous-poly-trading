方法论 / Methodology

世界杯的概率，是怎么算出来的？

我们不是“拍脑袋猜谁赢”，而是把一场比赛拆成一条流水线：先量两队实力，再算进球分布， 用过程数据校正，跑几万次模拟得到分布，用贝叶斯吸收最新消息，最后和市场盘口对比找偏差， 多个模型再融合成一个概率。下面用人话 + 公式逐个讲清楚——你可以直接动手玩两个计算器。

Ensemble

这套栈和 Kimi 公开的世界杯报告用的是同一类方法（Elo/FIFA + Poisson/Dixon-Coles + xG/xT + Monte Carlo + 贝叶斯 + 市场偏差）。 核心理念：模型的价值不在“消除不确定性”，而在系统地识别并诚实地表达不确定性。

1Elo / FIFA：两队到底谁强

它是什么

Elo 给每支球队一个分数（强队 ~2000，弱队 ~1500）。两队分差越大，强队赢面越大。 它最早用于国际象棋，是预测国家队比赛最稳的单一指标。FIFA 官方排名 2018 年后也改用了 Elo 化算法。

输入：两队 Elo 分输出：强队预期胜率

怎么算

EA = 1 / ( 1 + 10(RB − RA) / s ) // s = 600 R'A = RA + K · ( S − EA ) // 世界杯 K = 60；S=胜1/平0.5/负0

EA 是“强弱差异 → 期望分”。赛后用真实结果 S 反过来更新分数，强队爆冷输球扣分更多。

2Poisson / Dixon-Coles / Bivariate：把实力变成比分

它是什么

足球进球数近似服从 Poisson 分布：给定一队的“预期进球 λ”，就能算它进 0、1、2、3… 球各自的概率。 两队的进球分布一组合，就得到每个比分的概率，再加总成胜 / 平 / 负。

Dixon-Coles 修了两个毛病：① 低比分（0-0、1-1）真实世界更常见，加一个相关修正 ρ；② 近期比赛更重要，加时间衰减 ξ。 Bivariate Poisson 再显式建模两队进球的相关性。

输入：λhome, λaway输出：比分矩阵 → 1X2 / 大小球 / 双方进球

怎么算

P(进 k 球) = λk · e−λ / k! P(i:j) = P泊松(i | λH) · P泊松(j | λA) · τ(i,j) // τ = D-C 低比分修正 λ = α·xG_avg + (1−α)·进球_avg // α≈0.7，下一步的 xG 增强

参数起点（来自公开校准）：ρ ≈ −0.05，时间衰减半衰期 ≈ 2 年。

3xG / xT：看“过程”而不只看“结果”

xG（预期进球）

每脚射门按位置、角度、身体部位、防守压力，估一个“这脚该进的概率”（0–1）。一场所有射门的 xG 加起来， 衡量一队创造机会的质量——比单纯的“射正次数”或运气波动的真实进球更稳。

优秀 xG 模型的校准 Brier ≈ 0.08（盲猜 0.25）

xT（预期威胁）

把 xG 的思路推广到每一次触球/传球：球场切成网格，每个格子按“从这里最终能进球的概率”赋值， 传球/带球把球推进到更危险的格子就加分。用来量化战术质量（比如西班牙 tiki-taka 的渗透价值）。

作用：喂给 λ（进球模型）+ 战术相克分析

国家队一年正式比赛少（~15 场），所以我们用球员俱乐部 xG/xT 按出场时间加权当代理，补上样本不足。

4Monte Carlo：把一场比赛放大成整届赛事

单场模型只告诉你一场的胜平负。但“谁夺冠”“谁出线”要看整个赛程：小组 → 32 强 → … → 决赛。 做法是：用上面的单场概率，把整届 104 场随机模拟一遍，记录谁夺冠；这样跑 10,000–100,000 次， 数一数某队夺冠的频率，就是它的夺冠概率。模拟越多越稳——标准误差 ≈ √(p(1−p)/N)，跑 10 万次时通常 < 0.5%。

P(夺冠) ≈ (该队在 N 次模拟中夺冠的次数) / N // N ≥ 10⁴，夺冠/出线用 N = 5×10⁴

我们每天离线重跑一次（不在每次请求时跑），结果缓存复用。

5贝叶斯更新：来了新消息，概率怎么动

它是什么

从一个基准概率（同类型、同实力球队的历史成功率）出发，每来一条证据（伤停、首发官宣、状态） 就有依据地上调或下调，而不是推倒重来。输出一个主概率 + 80% 置信区间，而不是“可能/不可能”。

怎么算 + 我们的硬约束

P(H | E) ∝ P(E | H) · P(H) // 后验 ∝ 似然 × 先验

关键纪律：LLM 只能在统计先验之上做“有界调整”（按事件类型限制 ±X 个百分点），且 无证据 → 不许动概率。它负责统计模型看不到的东西：伤停、轮换、dead-rubber、墨西哥城 2240m 海拔、北美高温。

6市场偏差 + 融合：和盘口比，再合成一个数

市场偏差（研究信号）

Polymarket 等市场价格是“资金加权的群体共识”。我们先去掉抽水（overround）得到隐含概率， 再和我们的模型比：差值就是研究偏差信号。注意定位——市场只作为“共识偏差研究变量”， 是研究对象，不是投注建议。

偏差信号 = P模型 − P市场(去水)

融合（对数意见池 LogOP）

把统计概率、LLM 调整后概率、市场概率按各自的历史校准权重，在 logit 空间加权平均，再压回 0–1：

p融合 = Π pᵢwᵢ / [ Π pᵢwᵢ + Π (1−pᵢ)wᵢ ]

铁律：融合结果必须严格优于任一单路，否则就是没价值或有 bug。

怎么串起来：5 层模型栈

层做什么方法
Layer 1实力基线Elo + FIFA 排名 + 市场估值
Layer 2过程特征xG / xT 特征工程
Layer 3进球分布Dixon-Coles / Bivariate Poisson
Layer 4赛事模拟Monte Carlo（1万–10万次）→ 分布与置信区间
Layer 5动态更新Bayesian：按最新赛果/消息更新先验

出来后再做：和市场比偏差 → 多模型融合 → 给出主概率 + 80% 置信区间 + 置信度分档。

怎么知道我们准不准：公开 Brier 记分

我们用 Brier 分数给自己打分并公开——预测概率离真实结果越近越低越好。 逐场对照 Polymarket 市场、以及 Kimi 公布的预测。输了也照记，这才是可信度的来源。

Brier = (1/N) · Σ ( p预测 − o实际 )² // 单场 1X2 目标 < 0.20；盲猜 ≈ 0.22

历史回测预期：高置信约 85–90% 准、中置信 55–65%、低置信≈随机。即使高置信场也一定会有意外——这是足球。
